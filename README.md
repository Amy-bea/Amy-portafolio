##  API de contacto

El proyecto incluye un endpoint REST:

`POST /api/contact`

Cuenta con validaciones básicas para los datos del formulario y respuestas en formato JSON para indicar si la solicitud fue aceptada o si ocurrió un error.

**Nota:** Actualmente, el formulario valida y recibe la solicitud mediante la API, pero todavía no envía correos electrónicos ni almacena los mensajes en una base de datos.

## Instalación y ejecución

Para ejecutar el proyecto localmente necesitas tener Node.js instalado.

1. Clona el repositorio:

```bash
git clone https://github.com/Amy-bea/Amy-portafolio.git
```

2. Entra a la carpeta:

```bash
cd Amy-portafolio
```

3. Instala las dependencias:

```bash
npm install
```

4. Inicia el servidor:

```bash
npm run dev
```

5. Abre en tu navegador:

http://localhost:3000
