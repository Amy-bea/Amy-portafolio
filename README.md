# Portafolio digital de Amy

Portafolio personal desarrollado con Next.js, React, TypeScript y Tailwind CSS.

## Tecnologías
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Instalación

Necesitas tener Node.js instalado.

```bash
npm install
npm run dev
```

Abre http://localhost:3000 en tu navegador.

## API de contacto

El proyecto incluye `POST /api/contact` con validaciones básicas y respuestas JSON.
Por ahora valida la información, pero no envía correos ni guarda mensajes en una base de datos.

## Antes de publicar
- Reemplaza el correo de ejemplo.
- Agrega tus enlaces reales de GitHub y LinkedIn.
- Añade fotografías y capturas auténticas de tus proyectos.
- Revisa los textos y niveles de habilidades para que reflejen tu experiencia real.
- No agregues contraseñas ni claves privadas al repositorio.

## Despliegue
Importa este repositorio en Vercel y sigue la configuración recomendada para Next.js.
